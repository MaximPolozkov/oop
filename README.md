# **Примерно E-commerce**

Реализован class Product, Category.
Product инициализирует объект товаров. Category инициализируем объект категории.

Так же в модуле main.py реализована функция подгрузи данных по категориям и товарам из файла JSON.

Реализован две категории товаров и созданы классы, первый класс для смартфонов, второй для газонной травы. Которые для
наследуются от product, и могут добавляться в отдельную категорию.

Весь функционал протестирован с помощью pytest. 

Проект будет дополняться новым функционалом.
